# System Components and Analyst Interaction

Source basis: `app/streamlit_app.py`, `scripts/targeted_skeptical_queue.py`, and current export scripts in `scripts/`.

| Module | What the analyst sees | What the analyst does | Explainability / assistive signal shown | Output produced | Status (validated vs exploratory) |
|---|---|---|---|---|---|
| Run Lab: batch overview and run catalog | Latest run status, execution mode, run history, run-level filters, quick workflow prompts | Inspect run health, filter past runs, load/save study profiles, launch/inspect runs | Quick-workflow recommendation block, deterministic logic registry versions, run metadata | Run records (`runs`), profile records (`study_profiles`), optional research bundle JSON export | Exploratory/operational (not confirmatory evidence by itself) |
| Manual Annotation: Coding mode | Comment text with rank/context, top-cue comment preview, coder count, saved label summaries | Assign core labels and extra tags, save page-level coding decisions | Triage bucket/score, priority bucket/score, priority rationale, rule hints, optional automation trace | Annotation rows with workflow context in `annotations` | Validated evidence production step (pre-freeze; not yet canonical confirmatory evidence) |
| Manual Annotation: Adjudication mode | Disagreement-focused queue, prior coder labels, adjudication trace and notes | Resolve disagreements, mark rows adjudicated, add source/note | Disagreement flags and pre/post label trace (assistive context only) | Adjudicated annotation rows; preserved pre-adjudication core fields | Validated evidence production step (feeds resolved consensus for freezing) |
| Run Lab Step 1: Evidence Freeze | Freeze metrics (resolved, disagreements, positives), freeze ID/UUID/name, prevalence tables, freeze comparison | Select resolved-consensus runs, save named freeze, load/delete freeze, download freeze JSON/CSV | Explicit validated boundary badges, logic/version table, workflow metrics by triage/priority bucket | `evidence_freezes` records, freeze JSON, validation/system summary tables, export log entries | Validated (paper-facing anchor when using resolved-consensus scope) |
| Run Lab Step 3: Final analysis/export pack | Freeze-scoped summary cards, effects/ICC/prevalence previews, export controls | Generate and download paper export files | Validated boundary banner; scope tied to selected freeze run set | Final bundle JSON, prevalence CSV, effects CSV, appendix CSVs, export records | Validated if generated from freeze-scoped resolved evidence |
| Run Lab Step 2: Uncoded extension | Uncoded pool size, core-signal counts, AI-context counts, ranked candidate table | Prepare and download uncoded extension candidate lists | Signal score, auto labels, trace summary, language/low-info indicators | Uncoded extension candidate CSVs/full pool CSV | Exploratory only (explicitly outside confirmatory evidence layer) |
| Main Analysis (single-run cue model view) | H1/H2 cards, cue summary, niche snapshot, model effects, ICC, detailed response frame | Choose run and label source, run model view, export effects/response tables | Scope badge from selected label source (`resolved_consensus`, `adjudicated`, or assistive sources), model details expander | `conformity_effects_*`, `conformity_response_*`, `conformity_ranked_*` CSVs | Conditional: validated only when label source is `resolved_consensus`; otherwise exploratory/supportive |
| Cross-Run Analysis (pooled runs) | Pooled run metrics, H1/H2 summaries, pooled effects and ICC, combined response frame | Select multiple runs and label source, run pooled analysis, export combined tables | Same scope badge logic as Main Analysis, plus run-combination diagnostics | `combined_effects_*` and `combined_response_*` CSVs | Conditional: validated only with `resolved_consensus`; otherwise exploratory/supportive |
| Exploratory Hub (Scraped Data, Data Exploration, AI Disclosure Search, Comment Explorer) | Raw/comment tables, search/filter interfaces, disclosure and lexical signal panels | Pattern-hunt, inspect raw pools, run exploratory filtering/search | Assistive/exploratory boundary badges, weak-label and lexical signal indicators | Exploratory CSV exports (tool-specific) | Exploratory only |
| Targeted skeptical queue script | Ranked candidate videos/threads and run report artifacts in `outputs/` | Run targeted candidate generation for follow-up human coding | Deterministic heuristic score and staging label (`Exploratory candidate for validation`) | `targeted_candidate_videos.csv`, `targeted_candidate_threads.csv`, acquisition report + run metadata | Exploratory only until human-coded, adjudicated, and frozen |
| Workflow-evaluation script | Compact workflow-value metrics table (yield lift, burden proxy, disagreement concentration) | Recompute freeze-scoped workflow evaluation from local data | Transparent metric definitions and fixed simulation settings (where used) | `workflow_eval_summary.csv`, `workflow_eval_table.md`, `workflow_eval_notes.md` | Validation-support artifact (uses freeze-scoped resolved labels; does not create new evidence) |
| Workflow-comparison script | Reviewer-facing governance/architecture comparison table | Regenerate comparison matrix for manuscript inclusion | Explicit feature-level coverage claims (yes/partial/no) | `workflow_comparison_table.csv`, `workflow_comparison_table.md`, notes | Manuscript governance artifact (neither confirmatory nor exploratory data analysis) |
